This project focuses on cleaning, analyzing, and visualizing the sales data of ABC Electronics using Microsoft Excel. The dataset is preprocessed using Excel functions to remove inconsistencies and improve data quality.
Pivot Tables, Pivot Charts, and an interactive dashboard are used to generate meaningful business insights, enabling efficient analysis of sales performance across regions and product categories.
